# NeuroMD — редактор и генератор Markdown с обучающим разделом

Дата: 2026-10-12
Статус: утверждено к реализации

## 1. Цель

Учебный веб-проект для школьников: практический редактор Markdown с экспортом `.md`
и встроенный обучающий раздел, объясняющий роль формата Markdown в эпоху ИИ, понятие
`SKILL.md`, а также способы подключения скиллов — локально и в общий harness
(на примере Koda Desktop и Opencode).

## 2. Ограничения и ключевые решения

- **Чистый веб-стек.** Только HTML, CSS, Vanilla JS. Без сборки, без npm, без фреймворков.
- **Автономность.** Никаких внешних CDN. Собственный мини-парсер Markdown.
- **Офлайн-запуск.** Открытие `index.html` двойным кликом через `file://` должно работать.
  Поэтому используются классические `<script defer>` + IIFE, а НЕ ES-модули
  (ES-модули по `file://` блокируются CORS).
- **Многостраничник.** Отдельные HTML-страницы с общими CSS/JS.
- **Без эмодзи.** Только SVG-иконки из спрайта, монтируемого `js/icons.js`.
- **Стиль.** Тёмный нейрокиберпанк с мультиакцентом по разделам.
- **Доступность/производительность.** Уважение `prefers-reduced-motion`, адаптивность.

├── js/
│   ├── icons.js      монтирование SVG-спрайта иконок в DOM

## 4. Архитектура JS

Каждый файл — IIFE, экспортирующий ровно один объект в общий namespace `Neuro`:

- `Neuro.parser` — парсинг Markdown.
- `Neuro.editor` — поведение редактора.
- `Neuro.storage` — сохранение/загрузка/экспорт.
- `Neuro.templates` — шаблоны заготовок.
- `Neuro.bg` — canvas-фон.
- `Neuro.ui` — общий UI (навигация, аккордеоны, копирование, reveal).

Порядок подключения скриптов: `parser → storage → templates → editor → neuro-bg → ui`.
Каждый модуль при инициализации проверяет наличие DOM-узлов, чтобы один и тот же
набор скриптов безопасно подключался на разных страницах.

## 5. Страницы и содержание

### index.html
Hero с анимацией; блок «что это и зачем»; три карточки-перехода
(Редактор / Обучение / Skills); блок «почему Markdown важен в эпоху ИИ».

### editor.html
Тулбар, textarea, живой предпросмотр, панель метрик, шаблоны, режимы отображения,
переключатель темы, импорт/экспорт, экспорт в HTML, «Очистить», «Скопировать».

### learn.html
Что такое Markdown; базовый синтаксис с интерактивными примерами
(код слева — результат справа); почему ИИ предпочитает Markdown.

### skills.html
Что такое `SKILL.md`; анатомия скилла; пошаговое написание своего скилла;
готовые примеры скиллов.

### harness.html
Способы подключения скиллов: локально (папка со скиллами); общий harness на примере
**Koda Desktop** и **Opencode**; пошаговые инструкции; таблица сравнения.

## 6. Поток данных (редактор)

1. `textarea input` → debounce ~120 мс.
2. `Neuro.parser.parse(md)` — экранирование HTML → токенизация → HTML.
3. `preview.innerHTML = html`.
4. Автосохранение: `Neuro.storage.save(md)` в `localStorage` (тоже с debounce).
5. Экспорт: `Blob` + `<a download="*.md">`.
6. Импорт: `<input type="file">` + `FileReader`.

## 7. Компоненты

### Парсер (`Neuro.parser`)
Поддерживает: заголовки `#`–`######`; **жирный** / *курсив*; инлайн-код;
блоки кода ```` ``` ````; маркированные и нумерованные списки; чек-листы `- [ ]` / `- [x]`;
цитаты `>`; ссылки; картинки; горизонтальную линию `---`; таблицы; экранирование HTML
(защита от инъекций). API: `parse(md) -> html`.

### Редактор (`Neuro.editor`)
- Тулбар: обёртка выделения (жирный, курсив, код, заголовок, список, цитата, ссылка, таблица).
- Горячие клавиши: `Ctrl+B`, `Ctrl+I`, `Ctrl+K`, `Tab` (отступ).
- Три режима: редактор / просмотр / разделённый экран.
- Метрики: слова, символы, строки.
- Тема: тёмная / светлая.
- Кнопки: Очистить, Скопировать, Скачать `.md`, Скачать `.html`, Загрузить `.md`.

### Шаблоны (`Neuro.templates`)
- Обычный документ.
- README.
- `SKILL.md`.

### UI (`Neuro.ui`)
Навигация и мобильное меню; аккордеоны; кнопки «копировать код»; reveal-анимации
при скролле через `IntersectionObserver`.

### Фон (`Neuro.bg`)
Canvas: узлы-нейроны и синапсы, реагируют на курсор. Отключается при
`prefers-reduced-motion: reduce`.

## 8. Стиль

- Тёмная основа (почти чёрный фон) + мультиакцент по разделам:
  редактор — бирюза, обучение — фиолет, skills — маджента, harness — зелёный.
- Эффекты: неоновое свечение (glow), scanlines, glitch на заголовках, фоновая сетка,
  неоновые границы, плавные переходы.
- Иконки — SVG из спрайта, эмодзи не используются.
- Полная адаптивность (мобильные / планшет / десктоп).

## 9. Обработка ошибок

- Парсинг и доступ к `localStorage` обёрнуты в `try/catch`.
- При ошибке — мягкая деградация: предупреждение в интерфейсе, без падения страницы.
- Если `localStorage` недоступен (приватный режим) — редактор продолжает работать
  без автосохранения.

## 10. Проверка

Проверка выполняется в браузере на всех страницах проекта: базовая навигация,
мобильное меню, режимы редактора, импорт/экспорт, тема, копирование, аккордеоны,
Markdown-рендеринг, адаптивность и `prefers-reduced-motion`.

## 11. Вне рамок (YAGNI)

- Экспорт в PDF.
- Синхронизация, аккаунты, бэкенд.
- Полноценная поддержка всего спецификации CommonMark.
- Редактирование файлов на диске (только импорт/экспорт через браузер).
