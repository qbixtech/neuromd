Модуль 03 · подключение

Как подключить скилл

Написанный SKILL.md нужно поместить туда, где его увидит ассистент. Есть два пути: локально, в папке проекта, или через общий harness — хранилище скиллов, доступное сразу в нескольких средах.

01 / Что такое harness

Harness (обвязка, среда запуска) — это программа-агент, которая даёт модели инструменты: читать файлы, запускать команды, редактировать код. Именно harness решает, какие скиллы доступны и в каком порядке их подключать.

Локальные скиллы

Лежат в папке проекта или в домашней папке настроек. Видны только на твоём компьютере.

Общий harness

Скиллы лежат в общем хранилище и подключаются по имени. Одинаковы для всей команды.

Когда что

Локально — для своих экспериментов. Общий harness — чтобы делиться рабочими правилами.

02 / Подключение локально

Самый простой способ: положить скилл в папку, которую ассистент просматривает при запуске. Обычно это папка настроек агента в домашнем каталоге.

  1. Найди папку скиллов

    У большинства агентов это .<имя-агента>/skills/ в домашней папке пользователя. Например, для Koda CLI — ~/.kodacli/skills/.

  2. Создай подпапку для своего скилла

    Один скилл — одна папка. Внутри — файл SKILL.md. Имя папки делай коротким и понятным: lesson-notes, code-review.

  3. Скопируй файл

    Помести SKILL.md в созданную папку. Проверь, что заголовочный блок с name и description на месте.

  4. Перезапусти агента

    Скиллы читаются при старте. После добавления нового файла перезапусти harness, чтобы он его увидел.

Структура папок
.kodacli/
└── skills/
    ├── lesson-notes/
    │   └── SKILL.md
    └── code-review/
        └── SKILL.md

Проверка. Спроси у агента, какие скиллы ему доступны. Если твой скилл в списке — всё получилось. Если нет — проверь путь, имя файла (строго SKILL.md) и перезапусти harness.

03 / Пример: Koda Desktop

Koda — агент, который работает с твоими файлами и запускает команды. Скиллы дают ему готовые сценарии поведения.

  1. Открой папку скиллов

    Перейди в каталог настроек Koda. Скиллы хранятся в подпапке skills.

  2. Добавь свой SKILL.md

    Создай папку скилла и положи внутрь файл. Можно скопировать пример из раздела Skills.md.

  3. Перезапусти Koda

    При старте агент просканирует папку и загрузит описания скиллов.

  4. Дай задачу под скилл

    Опиши задачу так, чтобы она совпала с полем description — агент применит подходящий скилл автоматически.

Путь к скиллам (Windows) 
C:\Users\<Имя>\.kodacli\skills\my-skill\SKILL.md

04 / Пример: Opencode

Opencode — открытая среда для работы с ИИ-агентами в терминале. Здесь скиллы описываются отдельными файлами, а подключаются либо локально в проекте, либо через общий набор правил.

  1. Локально в проекте

    Создай папку для правил внутри проекта и положи туда SKILL.md. Так скилл путешествует вместе с кодом и попадает в репозиторий.

  2. Через общий набор

    Скиллы можно держать в общем каталоге конфигурации агента, чтобы они работали во всех проектах сразу.

  3. Опиши подключение

    В конфигурации агента укажи, откуда брать скиллы. Обычно достаточно пути к папке или имени набора.

  4. Запусти и проверь

    Запусти агента в терминале и попроси показать список доступных скиллов.

Пример структуры 
project/
├── .opencode/
│   └── skills/
│       └── my-skill/
│           └── SKILL.md
└── src/

Важно. Точные пути и названия настроек зависят от версии среды. Всегда сверяйся с документацией своего агента: общий принцип один — папка со скиллами и файл SKILL.md внутри, но конкретный путь может отличаться.

06 / Чек-лист

Имя строго SKILL.md, внутри папки скилла.

Поля name и description заполнены и понятны.

Шаги написаны глаголами, нет расплывчатых формулировок.

После перезапуска агент показывает скилл в списке доступных.
