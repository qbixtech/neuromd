# NeuroMD

Учебный веб-проект для школьников: редактор Markdown с экспортом `.md`/`.html`
и обучающий раздел о том, зачем формат нужен в эпоху ИИ, как писать `SKILL.md`
и как подключать скиллы — локально и в общий harness (Koda Desktop, Opencode).

Работает полностью офлайн: чистые HTML/CSS/JS без сборки, без npm и без CDN.
Открывается двойным кликом по `index.html` (протокол `file://`).

## Структура

```
├── index.html        главная страница
├── pages/            внутренние страницы
│   ├── editor.html   редактор Markdown
│   ├── learn.html    обучение: Markdown и ИИ
│   ├── skills.html   Skills.md: как писать скиллы
│   └── harness.html  подключение: локально и harness
├── css/              стили (base, layout, components, editor)
├── js/               скрипты (parser, editor, storage, templates, ui, neuro-bg, icons)
├── assets/           локальная иконка сайта
└── docs/             спека и план проекта
```

## Возможности редактора

- Живой предпросмотр с debounce, три режима: текст / разделённый / просмотр.
- Тулбар: жирный, курсив, код, заголовок, списки, чек-лист, цитата, ссылка,
  картинка, таблица, линия. Горячие клавиши: Ctrl+B / Ctrl+I / Ctrl+K / Tab.
- Шаблоны: обычный документ, README, `SKILL.md`.
- Экспорт: `.md` и `.html`. Импорт `.md`. Копирование в буфер.
- Автосохранение черновика в `localStorage`, тёмная и светлая темы.
- Метрики: слова, символы, строки.

## Безопасность и совместимость

- HTML в Markdown экранируется до разбора, а небезопасные URL-протоколы блокируются.
- Toast-уведомления выводят пользовательские данные через `textContent`.
- Страница работает офлайн через `file://`, без CDN и внешних зависимостей.
- Для доступности поддерживаются клавиатурная навигация, видимый focus и `prefers-reduced-motion`.
