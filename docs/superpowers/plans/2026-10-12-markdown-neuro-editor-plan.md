# План реализации: NeuroMD

Спека: `docs/superpowers/specs/2026-10-12-markdown-neuro-editor-design.md`
Дата: 2026-10-12

## Критерии успеха

- Все страницы открываются двойным кликом через `file://`, без сервера и сети.
- Редактор корректно рендерит Markdown, сохраняет в `localStorage`, скачивает `.md` и `.html`.
- Обучающий раздел объясняет Markdown, `SKILL.md`, локальное и harness-подключение
  (Koda Desktop, Opencode).
- Стиль нейрокиберпанк, без эмодзи, с анимациями, адаптивный.
- Все страницы проходят браузерную проверку без внешних зависимостей.

## Фаза 0. Каркас и стили

### Task 0.1 — Структура папок
Создать `css/`, `js/`, `assets/`. Проверка: директории существуют.
Зависимости: нет.

### Task 0.2 — `assets/icons.svg`
SVG-спрайт (`<symbol>`) с иконками: редактор, обучение, skills, harness, скачать,
загрузить, копировать, очистить, жирный, курсив, код, заголовок, список, цитата,
ссылка, таблица, тема, меню, внешняя ссылка, галочка, предупреждение.
Все — line-стиль, `stroke="currentColor"`. Без эмодзи.
Проверка: спрайт открывается, символы видимы.
Зависимости: 0.1.

### Task 0.3 — `css/base.css`
CSS-переменные (тёмная основа, акценты: бирюза/фиолет/маджента/зелёный),
reset, типографика, эффекты (glow, scanlines, glitch, фоновая сетка),
`prefers-reduced-motion`, тема `.theme-light`.
Проверка: подключается на пустой странице, переменные применяются.
Зависимости: 0.1.

### Task 0.4 — `css/layout.css`
Навигация, мобильное меню, футер, hero-сетка, контейнеры, адаптив (mobile/tablet/desktop).
Проверка: навигация и футер корректны на 3 разрешениях.
Зависимости: 0.3.

### Task 0.5 — `css/components.css`
Кнопки, карточки, код-блоки, аккордеон, таблицы, бейджи, метрики, toast-уведомления,
иконки через `<use>`.
Проверка: компоненты визуально корректны.
Зависимости: 0.3.

### Task 0.6 — `css/editor.css`
Стили редактора: тулбар, панель режимов, split-вью, textarea, preview, панель метрик,
адаптив редактора.
Проверка: страница редактора не ломается на мобильном.
Зависимости: 0.3.

## Фаза 1. Ядро JS

### Task 1.1 — `js/parser.js`
`Neuro.parser.parse(md) -> html`. Экранирование HTML, затем: заголовки, жирный/курсив,
инлайн-код, блоки кода, списки, чек-листы, цитаты, ссылки, картинки, `---`, таблицы.
Обёрнут в IIFE, `try/catch`.
Проверка: покрыто браузерной проверкой редактора.
Зависимости: 0.1.

### Task 1.2 — `js/storage.js`
`Neuro.storage`: `save(md)`, `load()`, `clear()`, `download(filename, text, mime)`,
`readFile(file, cb)`, `exportHtml(html)`. `try/catch` вокруг `localStorage`,
мягкая деградация.
Проверка: автосохранение и экспорт работают.
Зависимости: 0.1.

### Task 1.3 — `js/templates.js`
`Neuro.templates`: шаблоны «Документ», «README», «SKILL.md» (строками).
Проверка: шаблоны вставляются в редактор без ошибок.
Зависимости: 0.1.

## Фаза 2. Редактор

### Task 2.1 — `editor.html`
Разметка: подключение CSS, навигация, тулбар, textarea, preview, панель режимов,
метрики, кнопки (Очистить, Копировать, Скачать .md, Скачать .html, Загрузить .md),
выбор шаблона, переключатель темы, подключение скриптов в нужном порядке.
Проверка: страница открывается, элементы на месте.
Зависимости: 0.3–0.6, 1.3, 1.4.

### Task 2.2 — `js/editor.js`
`Neuro.editor`: рендер с debounce, метрики, тулбар-обёртки, хоткеи (Ctrl+B/I/K, Tab),
режимы (редактор/просмотр/split), тема, очистка, копирование, скачивание .md/.html,
загрузка .md, применение шаблонов, toast-ошибки.
Проверка: все функции редактора работают.
Зависимости: 2.1.

## Фаза 3. Общий UI

### Task 3.1 — `js/neuro-bg.js`
`Neuro.bg`: canvas с нейронами и синапсами, реакция на курсор, `requestAnimationFrame`,
отключение при `prefers-reduced-motion`. Только если есть `<canvas id="neuro-bg">`.
Проверка: фон анимируется, при reduced-motion статичен.
Зависимости: 0.1.

### Task 3.2 — `js/ui.js`
`Neuro.ui`: мобильное меню, аккордеоны, кнопки «копировать код», reveal-анимации
(IntersectionObserver), подсветка активной страницы в навигации.
Проверка: интерактив работает на всех страницах.
Зависимости: 0.1.
